# Archive: original one-time pipeline scripts

These two scripts were used once, on the author's own machine, to organise the raw files,
clean them, draw the first graphs and build the report document.
They contain absolute paths of that machine (for example `/home/claude/new/...`) and are kept
**for transparency only. They are not meant to be re-run from this repository.**

To re-check the numbers from the raw logs, use `../analyze_logs.py` (relative paths, runs anywhere).
